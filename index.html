년 예산안

연도를 고른 뒤 항목별 연간 예산을 입력하세요. (이월금 제외, 회계연도 기준)

회계감사

감사기간을 선택하고 "감사실시" 버튼을 누르면 자료를 산출합니다.

적요 코드관리

수입은 알파벳(A,B,C…), 지출은 2자리 숫자(01,02…) 코드예요. 은행 메모 맨 앞에 이 코드를 적으면 업로드 시 자동 인식돼요. 이월금·업무추진비 관련 특수항목은 이름은 못 바꾸지만 코드는 바꿀 수 있어요.

조합원명부

엑셀 원본을 받으면 실제 명부의 열과 양식에 맞춰 연결할 예정입니다. 현재는 임시 편집 양식입니다.

엑셀 파일을 업로드하면 실제 열 이름·서식에 맞춰 이 화면을 구성합니다. 아래 기본 항목은 임시 양식이며 원본 엑셀의 구조를 대신하지 않습니다.

각종현황

엑셀 원본을 받으면 실제 현황별 하위 메뉴와 입력 폼을 구성합니다. 현재는 임시 편집 양식입니다.

각종현황의 세부 항목은 엑셀 파일을 확인한 뒤 임의로 정하지 않고 원본 양식에 맞춰 추가하겠습니다.
